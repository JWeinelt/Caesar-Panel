# 🏛️Caesar Frontend
![Version](https://img.shields.io/badge/Version-v0.0.238-green)![Update](https://img.shields.io/badge/Last--Update-22.10.2025-blue)

This repo contains the frontend panel of **Caesar.**

## ⚙️ Requirements
- Java 17 or newer
- OpenGLES 2.0 compatible graphics
- At least 2GB memory
- At least 1GB disk space

## 💻 How to install
The Caesar panel always comes with the so-called **Caesar Worker.** The worker contains functions which are not possible with the panel itself.
We recommend using the **Caesar-Client installer package** to install the Caesar Panel on your computer. Head to the [Releases](https://github.com/JWeinelt/Caesar/releases) to download the full pack
alongside the current server version (if needed).
